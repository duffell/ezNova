# ezNova
A rapid radiative transfer code for generating supernova light curves using flux limited diffusion, with realistic opacities fitted from snopac.  Possibly one day we'll include multi-group. 

We are still building and testing ezNova.  DO NOT TRUST ANYTHING IT SAYS.

Feel free to look around though.


Compile by typing "make".

Run the attached example via

./eznova example.mod

Output results are stored in "report.dat"
